# Prismender 1.0

A Blender add-on which lets you import your Prisma 3D Scene into your
current Blender scene.

## Compatibility

- Blender v4.2 LTS
To be exact, it is meant to be most stable with that version. Earlier versions are not supported but the compatible versions field will be expanded in the future.

## Installation

In Blender: ```Edit > Preferences > Add-ons > Install... ```, directly select this ```.zip``` (Blender extracts the ```.py``` on its own), then enable ```Prisma 3D Importer``` in the list.

(NB: No need to install Python. Blender embeds its own Python environment!!!)
